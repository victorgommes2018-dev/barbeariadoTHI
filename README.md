# Barbearia do THI — Landing Page Demonstrativa

Landing page estática, responsiva e pronta para publicação em Vercel/Netlify.

## Arquivos

- `index.html` — estrutura, SEO e dados estruturados
- `styles.css` — identidade visual, responsividade e animações
- `script.js` — menu mobile, animações de entrada e ano do rodapé
- `assets/` — imagens derivadas da captura do Instagram fornecida

## Publicação

Não há build ou instalação de dependências.

### Vercel
1. Envie a pasta para um repositório GitHub.
2. Importe o repositório no Vercel.
3. Framework Preset: `Other`.
4. Build Command: deixe vazio.
5. Output Directory: `.`

### Netlify
Arraste a pasta para o deploy manual ou conecte o repositório GitHub.

## Observações para a demonstração

- Não foram inventados preços, avaliações, profissionais, certificações ou anos de experiência.
- Como o horário de funcionamento não foi fornecido, ele não aparece como informação factual.
- Os três visuais da galeria são recortes da captura do Instagram fornecida para esta demonstração.
- O endereço e o WhatsApp usados são os dados fornecidos.
- O link "Como chegar" usa uma busca do Google Maps baseada no endereço informado.
- Antes de publicar definitivamente, substitua os recortes por fotos originais em maior resolução, se o proprietário fornecer autorização e arquivos.
